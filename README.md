# OrgoProducts

OrgoProducts is an ecommerce website for browsing and purchasing organic products. The project is primarily built with PHP, with CSS and HTML used for the user interface and Hack included in the codebase.

## Overview

This project provides a foundation for an online organic-products store, including product-focused pages and a web-based shopping experience.

## Tech Stack

- **PHP** — Core application logic
- **CSS** — Styling and layout
- **HTML** — Page structure
- **Hack** — Supporting source code

## Getting Started

### Prerequisites

- PHP 8.0 or later
- A local web server such as Apache or Nginx
- A browser

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/shah-bhavy/OrgoProducts.git
   ```

2. Move into the project directory:

   ```bash
   cd OrgoProducts
   ```

3. Configure the project for your local PHP web server.

4. Open the application in your browser through the local server.
